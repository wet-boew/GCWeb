The PII scrub component detects Personal Identifiable Information (PII) in the form fields you flag, shows the user a confirmation dialog with the redacted values, and replaces those values before the form is submitted.

About the detection patterns on this page

This page loads an updated version of the wb.findPotentialPII() core helper, mirroring the patterns proposed in wet-boew pull request #10117. On top of the patterns already shipped in WET-BOEW, it detects:

  • obfuscated email addresses, including spaced-out domains and addresses with no top-level domain
  • civic addresses in English and in French, with or without a direction or an article
  • post office boxes (PO Box, case postale, casier postal, and their abbreviations)

The override is temporary and lives in components/pii-scrub/pii-scrub.js. It should be removed once the pull request is merged upstream and the wet-boew dependency is updated.

How it works

  • Add the wb-pii-scrub class to the form element.
  • Add the data-scrub-field attribute to each field whose value should be checked for PII.
  • Give each flagged field a label. Wrap the label text in <span class="field-name"> when the label contains extra text you do not want repeated in the confirmation dialog.
  • Optionally configure the component with the data-wb-pii-scrub attribute:
    • scrubChar: the string used to replace detected PII. Defaults to ********.
    • moreInfo: HTML shown in the view more section of the default dialog.
    • modalTemplate: a selector matching a <template> inside the form, used instead of the default dialog. Place a data-scrub-modal-fields element where the redacted values should be listed, and put data-scrub-submit on the confirm button.

Full option details are available in the PII scrub documentation.
