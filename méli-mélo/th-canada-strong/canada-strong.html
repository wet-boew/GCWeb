Styles for the Canada Strong campaign pages. Refer to the working examples for a visual of the code below.

Working examples

  • Landing page layout
  • Support page layout

CSS classes

canada-strong-page
Wrapper for the campaign content. Sets the navy text and heading colour.
canada-strong-hero
Full-width hero with a light blue background and a decorative background image. Use with bg-cover and data-bgimg-srcset. Its children are canada-strong-hero__overlay, canada-strong-hero__row and canada-strong-hero__copy.
canada-strong-section-header
Maroon title bar with white heading text.
canada-strong-audience-card
Maroon card with white heading, text and link. Use with well.
canada-strong-support-section, canada-strong-support-grid, canada-strong-support-card
Grid of equal-height bordered cards with a round icon (canada-strong-support-card__icon). Use the card class with panel panel-default.
canada-strong-closing-band, canada-strong-closing-panel
Light blue band with a navy closing panel, a round white icon (canada-strong-closing-panel__icon), white heading, text and link. Use the panel class with well.
canada-strong-banner
Maroon banner with a white h1 and an image, used on sub pages. Use with panel.

Theme elements

The hero and the banner hold the page title. In the working examples below they use a h2 so the documentation page keeps a single h1, and the inner container is replaced with container-fluid because these examples already sit inside a container. On a real page, use <h1 property="name" id="wb-cont">, which is what draws the short red underline.
